# GPU 장면 바이너리 저장 비교

미배포 1.37.3 유지. 2026-11-01.

## 변경

기존 저장 경로는 이미 만들어진 LFSC 장면 패킷을 Base64로 바꾸고 전체 장면을
JSON/UTF-8로 인코딩한 뒤 zlib로 압축했다. 복원 시 반대 변환을 수행했다.

새 경로는 `scene_cache_packet.py`가 작은 바이너리 메타데이터와 LFSC 패킷을
직접 저장한다. 64MiB 단위로 기존 Rust LZ4 블록 압축을 적용하고, 압축 효과가
낮거나 작은 데이터는 원문으로 보관한다. 전체 패킷은 256MiB로 제한하며,
메타데이터·명령 수·청크 크기를 검사한 뒤 SHA-256으로 복원 무결성을 확인한다.
명령별 Python 객체 복원과 JSON/Base64 변환은 새 저장 경로에서 실행하지 않는다.

SQLite의 용량 제한·오래된 항목 제거·트랜잭션, 보호/수정 문서와 뷰포트 장면의
저장 제외 규칙은 유지한다. 영구 저장 형식에 pickle은 사용하지 않는다.
이전 Python 참조 장면의 JSON 저장은 비교 검사와 호환 경로로 남긴다.
캐시 형식 식별자를 15에서 16으로 변경했으므로 기존 캐시는 한 번 다시 생성한다.

## 비교 방법

ACB 2015/2019 각각 두 방식으로 새 프로세스 5회, 순서를 번갈아 총 20회 측정했다.
동일한 현행 Rust 컴파일러로 장면을 만든 뒤, 그리기 패킷이 byte 단위로 같은지
확인했다. 아래 시간에는 PDF 컴파일과 프로세스 시작을 포함하지 않는다.

저장/복원은 실제 SQLite 연결·기록·재읽기를 포함한다. OS 파일 캐시는 강제로
비우지 않았으며 임시 데이터베이스를 사용했다. 직렬화만의 시간도 따로 측정했다.

| 5회 중앙값 | ACB 2015 기존 → 바이너리 | ACB 2019 기존 → 바이너리 |
|---|---:|---:|
| SQLite 저장 | 151.25 → 42.05ms (-72.2%) | 378.51 → 92.01ms (-75.7%) |
| SQLite 복원 | 68.67 → 29.99ms (-56.3%) | 202.68 → 54.95ms (-72.9%) |
| 인코딩·압축만 | 119.62 → 13.64ms | 332.81 → 25.25ms |
| 압축 해제·디코딩만 | 45.16 → 6.29ms | 148.86 → 23.74ms |
| 저장 크기 | 1,378,851 → 1,376,288 bytes | 2,881,902 → 2,661,453 bytes |

중간 Base64/JSON 텍스트 버퍼도 생성하지 않게 된다. 전체 프로세스의 최대 메모리
감소량은 이번 저장 벤치마크에서 별도로 측정하지 않았다.
이 수치는 장면 저장·복원 단계의 개선이며 GPU 그리기 속도나 전체 앱 시작 시간의
개선율로 합산하지 않는다.

## 검증

- 컴파일된 장면의 메타데이터와 패킷 복원, 비압축 데이터, 여러 청크 경계 검사.
- 잘림·내용 변조·비정상 크기·잘못된 압축 헤더를 캐시 실패로 처리하는지 확인.
- 기존 보호 문서 제외, 용량 제한, 페이지/파일 변경 무효화, 작업 프로세스 복원 검사.
- ACB 2015/2019의 맞춤·800% 총 4개 화면에서 저장 전후 GPU 출력 변경 채널 0,
  최대 채널 차이 0. 800%의 패킷 크기는 각각 약 29.7MiB, 57.6MiB였다.

원시 측정과 개인 문서 관련 결과는 `tmp/rust-audit/binary-cache-*`에만 보관한다.
재현:

```text
python -m tests.benchmark_scene_storage --runs 5 --output <JSON> <PDF...>
python -m tests.audit_scene_cache_gpu --output <JSON> <PDF...>
python -m tools.ci.run_tests --single tests.test_scene_cache_packet
python -m tools.ci.run_tests --single tests.test_scene_disk_cache
python -m tools.ci.run_tests --single tests.test_native_scene_compiler
```

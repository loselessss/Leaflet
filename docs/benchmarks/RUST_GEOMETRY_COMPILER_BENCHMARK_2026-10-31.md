# Rust 좌표·경계·병합 경로 생성 비교

2026-10-31 · 미배포 1.37.3 유지 · Direct2D ABI 24/장면 형식 변경 없음

## 기준과 변경

1번 도형 배열 packing 최적화(`7df549c`)가 적용된 상태에서 2번만 비교했다.
Rust 확장에 다음 세 연산을 추가했다.

- 경계 계산: 점 목록, 변환된 점 목록, X/Y 목록을 만들지 않고 한 번 순회하며 경계를 구한다.
- 좌표 변환: 기존 순서대로 float64 곱셈·덧셈을 수행하고 동일한 명령 tuple을 만든다.
- 병합 경로 생성: 여러 경로의 변환 결과를 각각 별도 tuple로 만들지 않고 최종 명령 목록에 모은다.

병합 가능 여부, 겹침 판단, 색·투명도·스타일·최대 병합 크기는 기존 Python 규칙을
유지한다. 결과 재사용이나 새로운 캐시는 추가하지 않는다. 무한대·NaN 및 연산 overflow는
Python 경로로 돌아가 기존 NaN 부호/전파까지 보존한다. 초기 후보의 NaN 부호 차이를
발견한 뒤 이 fallback을 추가했으며 아래 결과는 보완 후의 빌드다.
확장이 없거나 1번만 포함된 이전 확장인 경우에도 Python 추출 경로를 사용할 수 있다.

## 비교 방법

```text
python -m tests.benchmark_geometry_compiler <PDF...> --verify-render --output <JSON>
```

각 문서 페이지 1, source scale 1에서 매번 새 PDF를 열고 장면을 추출한다.
페이지 로드 후 `vector_page_from_pymupdf` 전체를 측정한다. 문서 열기·프로세스 시작·
GPU 업로드·최종 그리기는 이 시간에 포함하지 않는다. 1번 최적화는 두 방식 모두 유지한다.
Python/Rust 순서를 번갈아 실행하고 워밍업 1회 뒤 각각 7회 중앙값을 구한다.
문서 순서를 바꿔 독립 실행 2회를 진행했다. 모든 표본에서 전체 VectorPage의 좌표,
명령, 이미지 바이트, 변환·마스크·스타일 메타데이터가 Python 결과와 같은지 검사했다.

두 번째 실행에서는 워밍업에 각 방식의 새 GPU 장면을 만들고, 1200×900 출력의
맞춤·100%·800% 중앙 화면을 GPU 완료/readback 뒤 비교했다. 이 검증은 추출 타이머 밖이다.
800%도 source scale 1을 사용하므로 고해상도 이미지 재추출 속도를 측정한 것은 아니다.

## 결과

| 실행 | 문서 | 추출 Python → Rust (ms) | 단축 |
|---|---|---:|---:|
| 1 | ACB 2015 | 1,185.32 → 995.64 | 16.0% |
| 1 | ACB 2019 | 1,026.43 → 906.79 | 11.7% |
| 2 | ACB 2015 | 1,174.04 → 989.66 | 15.7% |
| 2 | ACB 2019 | 1,020.99 → 886.87 | 13.1% |

ACB 2015는 4,756개, 2019는 277개 장면 항목으로 기존과 같다.
두 실행의 모든 추출 결과가 일치했고 두 번째 실행의 6개 화면 픽셀 해시도 일치했다.
1번의 GPU 자원 준비 단축률과 이 추출 단축률은 다른 구간이므로 더하거나 곱해
전체 앱 개선율로 표현하지 않는다. 실제로 약 120~190ms의 추출 시간이 추가로 줄었다.

## 메모리 관찰

각 문서에서 추출된 가장 긴 경로(명령 8,191개)에 affine 변환을 적용해 경계를 구하는
호출 하나를 `tracemalloc`으로 관찰했다. 입력 경로는 측정 전에 준비했다.

| 문서 | Python 할당 peak | Rust 경로의 Python 할당 peak |
|---|---:|---:|
| ACB 2015 | 3,172,960 bytes | 168 bytes |
| ACB 2019 | 3,182,232 bytes | 168 bytes |

이는 해당 호출의 **Python 추적 할당량**이며 전체 프로세스 RSS, Rust allocator 또는
VRAM 계측이 아니다. 앱 메모리가 그대로 3MiB 감소한다는 뜻이 아니다. 좌표에 비례하는
중간 Python 목록이 없어졌다는 근거이며, 최종 명령 tuple과 PDF/이미지 메모리는 남는다.

원본 PDF와 표본 JSON은 비공개 `tmp/rust-audit/geometry-final-*.json`,
메모리 관찰은 `geometry-memory.json`에 보관한다. 비교 도구와 수치 경계값·fallback·
병합 순서/스타일 검사는 저장소에 포함한다.

# GPU 지원 범위 확장 검증 — 2026-11-05

대상: 미배포 1.38.0. 비교 기준은 확장 전 `e3c32898` 개발본이다.
양쪽 모두 PyMuPDF 2.1 / MuPDF 1.28.6을 사용한다. 개인 PDF와 원본 화면은 저장소에 포함하지 않는다.

## 바뀐 처리

| 항목 | 확장 전 | 확장 후 |
| --- | --- | --- |
| CMYK 투명 그룹 | 미지원 조합에서 페이지 CPU 대체 | RGB 색 공간으로 근사해 GPU 합성 |
| 비격리 배경 의존 혼합 | 미지원 조합에서 페이지 CPU 대체 | GPU에서 알파를 별도로 구해 배경을 제거한 소스 복원 |
| 0 너비 점선 | 페이지 CPU 대체 | GPU hairline 스타일 |
| 복합 Type3 채움 글자 | 글자 실행 단위 비트맵 | 경로·색상·클립·원본 이미지를 GPU 명령으로 전개 |
| 패턴·메시·마스크 | 패턴·음영·coverage를 CPU 비트맵으로 준비 | 벡터 반복·GPU gradient mesh·GPU coverage |

CMYK 혼합 공간 자체를 GPU에서 재현하는 구현은 아니다. 색상과 일부 경계 차이를 허용하며
정밀 확인에는 CPU 모드를 사용한다. PDF 해석, 원본 이미지 디코딩, 색상·기하 정보 준비는 계속 CPU가 맡는다.

리소스 한도를 초과한 패턴·메시와 깊거나 큰 배경 의존 그룹, 기존의 작은 knockout
영역 보정에는 제한된 CPU 영역 처리를 남긴다. 더모아젠과 ACB 2015가 모든 조건에서
GPU 전용이 되었다고 해석하면 안 된다.

## 검증

- 재현 PDF 27종: CMYK와 여러 혼합 모드, Type3 벡터·색상·다중 경로·클립·이미지,
  0 너비 점선, mesh type 4~7, 비선형 함수·사용자 domain, 패턴, 소프트·휘도·이미지 마스크.
- 일반 재현 사례는 CPU 글자·패턴·음영·합성 비트맵 태그 없이 컴파일되며 실제 GPU 픽셀을 CPU 기준과 비교한다.
- 3200%에서는 중앙과 화면 모서리의 제한된 영역을 비교한다. 화면 밖 마스크의 내용을 함께 생략하여
  크기 0인 캡처와 스코프 불균형을 방지한다. 가는 점선은 화면에 보이는 점선 간격도 별도로 비교한다.
- 더모아젠 두 페이지, ACB 2015·2019, 전자세금계산서 한 페이지를 개발본과 실행 파일에서
  각각 준비했다. 100% 준비·800%·3200%의 총 15개 조건에서 패킷이 동일하고 GPU 프레임을 생성했다.
- 전체 자동 테스트 857개를 통과했다. 실행 파일의 기본 실행, 한영 혼합 OCR, 로컬 읽기 순서 분석도 통과했다.
  이전 입력 DLL을 새 작업 프로세스와 섞으면 `native scene ABI mismatch`로 명확히 차단한다.
- 렌더러 ABI 25, MuPDF 입력 ABI 2, 장면 저장 의미 버전 20을 함께 사용한다.

배경과 무관한 source-over 내용은 한 번의 격리 합성으로 동일한 결과를 얻는다.
마스크 생성 안의 혼합은 독립 target에서 계산되므로 이 판정을 막지 않는다.
내부 혼합이 실제 배경에 의존하는 경우만 GPU 알파 복원용 두 번의 그리기를 사용한다.

## 측정 조건

1200×900 화면에서 매번 새 작업 프로세스와 새 GPU 장면을 사용한다. 준비 시간은 3회,
GPU 완료 시간은 5회를 이전·이후 번갈아 측정한 중앙값이다. GPU 완료 시간에는 동기화된
진단용 픽셀 읽기와 프레임 종료가 포함되며 불변 자원 업로드는 제외한다. 표시 경로에서는 픽셀을 CPU로 읽지 않는다.
GPU 장치는 유지하고 조건별 한 차례 준비 그리기 후 측정한다. 결과 스냅샷 재사용은 끈다.

첫 화면은 페이지 전체를 준비한 뒤 화면에 맞춰 그린다. 800%와 3200%는 화면 중앙과
주변 25% 여유 영역의 이미지 자원만 준비한다. 따라서 페이지 전체를 해당 배율로 준비한
과거 기록과 직접 비교하지 않는다. 메모리는 준비 작업 프로세스의 peak working set이며 GPU 메모리가 아니다.

이미 준비된 장면을 이동하거나 확대 애니메이션으로 표시하는 매 프레임의 시간은 아니다.

이번 변경의 주된 이득은 지원 범위와 GPU에서 직접 계산하는 효과의 확대다. 이미 CPU에서
이미지 알파를 결합하던 문서는 GPU 마스크의 별도 생성·적용 비용이 추가된다. 이 측정에서는
ACB 2019의 첫 화면과 더모아젠의 일부 조건이 느려졌고, 메모리도 전반적으로 감소하지 않았다.
전체 문서에 대한 속도·메모리 개선으로 홍보하면 안 된다.

배경과 무관한 내용을 한 번만 그리도록 바꾼 뒤 실제 문서의 이전 두 번 그리기 결과와도 비교했다.
화면 맞춤의 평균 RGB 채널 차이는 ACB 2015 0.00010, ACB 2019 0,
더모아젠 1쪽 0.00015·2쪽 0이었다(0~255 기준). 새 실행 파일과 개발본의 장면은 동일하다.

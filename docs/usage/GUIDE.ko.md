# Leaflet 사용 안내

달 버튼 **우클릭**으로도 문서 포함·제외 메뉴를 엽니다. **보기 → 명령 모음**의 체크로 리본을 켜고 끕니다. 숨긴 뒤에도 같은 메뉴에서 다시 표시할 수 있습니다.

리본의 **달 아이콘**으로 밝은 모드·다크 모드를 즉시 전환할 수 있습니다. **보기 → 다크 모드**에서
**밝은 모드 / 다크 모드 (문서 포함) / 다크 모드 (문서 제외) / Windows 설정 따르기**를 선택하며, 다시 실행해도
선택을 기억합니다. PDF 원본 색상은 유지합니다. 읽기 리본의 **마법봉 아이콘**으로 편집 창을 엽니다.

**다크 모드 (문서 포함)**은 앱과 문서를 함께 어둡게 표시합니다. **문서 제외**는 앱만 어둡게 표시합니다.
밝은 모드에서는 문서도 원본 색상으로 돌아옵니다. 달 버튼은 마지막 포함 여부를 기억하며,
Windows 설정을 따르면 문서도 선택한 포함 여부에 따라 함께 전환됩니다. 기본값은 문서 포함입니다. 밝은 종이와
글자를 읽기 편하게 바꾸고 사진·어두운 영역은 가능한 한 유지합니다. 종이처럼 보이는
스캔 문서도 처리하며, 복잡하거나 판정하기 어려운 그림은 원래대로 남을 수 있습니다.
정확한 색상 확인에는 옵션을 끄세요. 저장·인쇄·내보내기 결과에는 영향을 주지 않습니다.

첫 화면의 **읽기 모드 / 편집 모드** 표시로 현재 작업 창을 확인할 수 있습니다.
**편집 모드로 전환 / 읽기 모드로 전환** 버튼으로 다른 모드를 열 수 있습니다. 새 창이 준비되면 비어 있는 이전 첫 화면은 닫힙니다.
시작 메뉴의 **Leaflet**은 읽기 모드, **Leaflet 편집기**는 편집 모드로 열립니다.
보기 → 화면 렌더러에서 자동·GPU·CPU를 선택하고 벡터 페이지 캐시 용량을 조절할 수 있습니다.
렌더러와 캐시 용량 변경은 즉시 반영됩니다. 렌더러를 바꿔도 현재 페이지·배율·보고 있던 위치와 미저장 변경 사항은 유지됩니다.

주변 벡터 페이지는 메모리 여유에 따라 최대 32페이지까지 순서대로 준비합니다. 최근 장면은 바로 사용하며,
밀려난 장면은 RAM에 압축해 보관합니다. 캐시 예산의 1/4 이내(최대 256MiB·128개)를 압축 보관에 쓰고
압축 중 원본도 예산에 포함합니다. 문서 수정·닫기·메모리 부족 때 정리하며, 모든 페이지를 한꺼번에 준비하지 않습니다.
RAM에서 복원한 장면도 GPU 업로드·합성은 필요할 수 있습니다.

GPU 가속으로 부드럽게 확대·이동하고, 텍스트 편집·페이지 구성·주석·오프라인 OCR을
사용할 수 있는 Windows PDF 리더·편집기입니다.


GPU 장면은 MuPDF 네이티브 입력을 받아 Rust에서 컴파일합니다. 백그라운드 열람 작업은 독립 Rust 프로세스가 PDF 열기부터 장면 준비까지 맡고, Python은 창과 페이지 작업을 제어합니다. 글자·윤곽선 글자·텍스트 클립은 벡터로 유지합니다. 정확한 표현 확인에는 CPU 모드를 사용합니다.

EPS를 열려면 PC에 [Ghostscript](https://www.ghostscript.com/releases/gsdnld.html)가 설치되어 있어야 합니다. 임시 PDF로 변환해 열고 편집 결과는 PDF로 저장합니다. Ghostscript는 설치 파일에 포함되지 않습니다.

수정한 AI 파일은 PDF로 저장합니다. Illustrator 호환 저장은 기본으로 켜져 재편집 정보를 제거하고 현재 PDF 내용으로 엽니다. 해제하면 기존 정보를 보존하지만 이전 내용이 다시 나타날 수 있습니다. AI 파일 생성이나 원본 레이어·효과 편집 구조 보존 기능은 아닙니다.

## 읽기 순서로 복사

**편집 → 읽기 순서로 복사** 또는 **Ctrl+Shift+C**를 사용합니다. 선택한 글이
있으면 그 부분만, 선택이 없으면 현재 페이지 전체를 복사합니다. PC 안의 AI가
단과 문단을 분석해 원래 글의 순서를 정돈합니다. 글의 내용은 고쳐 쓰지 않으며,
복잡한 배치에서는 복사 결과를 확인해야 할 수 있습니다. 스캔 페이지는 먼저 OCR을
실행해 주세요. 분석은 취소할 수 있고 작업 후 모델 메모리는 정리됩니다.
일반 Ctrl+C는 기존대로 동작합니다.

## 다운로드

**안정 버전은 [Microsoft Store](https://apps.microsoft.com/detail/9PCB1BH4WBDT?hl=ko-kr&gl=KR&ocid=pdpshare)에서 설치하세요.**

최신 일반 설치파일은 [GitHub 릴리스](https://github.com/loselessss/Leaflet/releases/latest)에서도 받을 수 있습니다.

시작 메뉴의 **Leaflet** 또는 **Leaflet 편집기**로 실행합니다.
리더의 **편집 → 편집 창에서 열기**(Ctrl+E), 편집기의 **리더로 돌아가기** 버튼으로 모드를 전환합니다.
자세한 사용법은 프로그램에서 **F1**을 누르면 볼 수 있습니다.

## 주요 기능

- **읽기:** GPU 렌더링, 최대 3200% 확대, 검색, 책갈피, 드래그로 분리·병합하는 탭,
  두 장 보기와 프레젠테이션.
  정밀 GPU 갱신은 타일별 임시 표면의 수명을 계획해 묶음 할당하며 저장소 슬롯 수를 제한합니다.
  작은 복합 삽화는 확대 배율에 맞는 제한된 투명 배경 이미지로 구성하며 주변 글자는 벡터로 유지합니다. 삽화의 색·경계 표현은 달라질 수 있으므로 정밀 확인에는 CPU 모드를 이용할 수 있습니다.
  이미지·알파 마스크를 결합해 합성과 메모리를 줄이며, 필터링된 이미지 경계는 소폭 달라질 수 있습니다.
  준비 중 결합이 끝난 중간 알파 소스를 해제해 제한된 GPU 이미지 예산 안에서 더 높은 소스 해상도를 처리합니다.
  고배율에서는 보이는 이미지 영역과 상하좌우 최대 한 화면의 이동 여유분만 준비하며 글자·선은 벡터로 유지합니다. 화면을 이동하면 새 영역을 백그라운드에서 준비해 교체합니다.
- **편집:** 텍스트·글꼴·크기·색상 수정, 사각형·이미지 추가와 이동·크기 조절.
  PDF에 직접 배치된 기존 이미지의 선택·이동·크기 조절·삭제.
- **페이지:** 순서 변경·회전·자르기·병합·분리·추출,
  페이지 크기·도련 조정과 제본·접기 안내선 추가.
- **아트보드:** 편집 작업면에서 여러 페이지를 함께 보고 확대·이동하거나 페이지 번호를 드래그해 화면 배치를 조절합니다. 더블클릭하면 정밀 편집으로 돌아가며 PDF 순서는 그대로입니다.
- **주석:** 리더·편집모드에서 형광펜과 메모를 추가하고 원본 PDF에 저장하거나 사본으로 저장합니다. 텍스트 워터마크는 편집모드에서 사용할 수 있습니다.
  Ctrl+Shift+M으로 별도 주석 관리 창을 열어 검색·위치 이동·내용 편집·삭제와 실행 취소·저장을 할 수 있습니다.
- **OCR:** 한국어·영어 스캔 문서를 컴퓨터에서 인식하고 검색 가능한 텍스트 추가.
- **출력:** 인쇄, PDF 압축과 PDF·이미지 간 변환.
  다른 이름으로 저장에서 문서 메타데이터·Leaflet 개체 재편집 정보 제거를 각각 선택.

같은 줄의 가까운 글자 조각은 클릭하여 함께 수정하고, 여러 줄을 상자로 드래그하면
문단으로 편집합니다. 작은 속성창에서 상자 크기·정렬·줄 간격을 조절하고 PDF 출력
미리보기를 확인하세요. 문단 편집에서는 Enter로 줄을 바꾸고 Ctrl+Enter로 적용합니다.
글이 넘치면 상자를 늘리거나 글자 크기를 줄여야 적용할 수 있습니다.

텍스트는 선택한 상자 안에서 줄을 바꾸며, 주변 문서 전체를 자동으로 재배치하지 않습니다.
대체 글꼴의 모양은 원본과 다를 수 있습니다. Leaflet에서 추가한 개체는 저장 후에도
편집할 수 있습니다. 편집모드에서 기존 이미지를 클릭하면 바로 선택해 조정할 수 있습니다.
그룹·클리핑 범위 안의 이미지와 기존 벡터 도형은 아직 개별 편집을 지원하지 않습니다.

## 단축키

편집 창의 **그림·개체 배치**에서 그림을 드래그하면 페이지·다른 개체의 가장자리와 중심에 자석처럼 붙습니다.
**자석 정렬** 버튼이나 속성창에서 켜고 끌 수 있습니다. **Ctrl**을 누르면 안내선만 남겨 자유롭게 이동하고, **Shift**는 직선 이동입니다.

| 단축키 | 기능 |
| --- | --- |
| Ctrl+O / Ctrl+S / Ctrl+P | 열기 / 저장 / 인쇄 |
| Ctrl+F | 텍스트 찾기 |
| Ctrl+E | 편집 창 열기 / 텍스트 편집 켜기·끄기 |
| Ctrl+Shift+P | 페이지 구성 |
| Ctrl+Shift+A | 편집모드 아트보드 / 정밀 페이지 편집 전환 |
| Ctrl+Shift+M | 별도 주석 관리 창 열기 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Delete / 방향키 / Shift+방향키 | 편집 캔버스에서 선택한 개체 삭제 / 이동 / 크게 이동 |
| Esc / Space 누르기 | 조작 취소 또는 개체 선택 해제 / 편집모드에서 임시 화면 이동 |
| 마우스 가운데 버튼 드래그 | 도구를 바꾸지 않고 문서 화면을 상하좌우 이동 |
| F1 | 도움말 |

# 클립·마스크 합성 셰이더 비교 (2026-10-19)

기준은 origin/main에 푸시한 f8c2b90의 1.37.0 개발 DLL이다. 앞선 파이프라인·화면 밖 명령 묶음·전체 target 사각형 생략을 모두 포함한다. 이번 변경은 클립·마스크를 닫을 때 세 Composite 노드를 하나의 전용 픽셀 셰이더로 대체한다. 렌더 결과 캐시를 늘리지 않으며 매 표본의 장면 identity도 새로 만든다.

ACB 2015의 화면 맞춤 완료 중앙값은 두 회차에서 각각 15.9%, 5.1% 줄었고, 200%는 18.7%, 17.2% 줄었다. 100%는 한 회차에서 느려지고 다른 회차에서는 빨라져 일관된 개선으로 보지 않는다. ACB 2019의 중앙값 차이는 작다. 동일한 원래 타일 면적·해상도를 유지한 전체 완료 비교이며, 모든 확대 단계나 PDF에 대한 개선율로 일반화하지 않는다.

## 구현과 정확성

- 기존 계산은 inside = 결과 × coverage, outside = 배경 × (1 − coverage), 최종 = inside + outside다. 동일한 세 입력을 한 셰이더에 연결해 CPU 측 effect 생성·설정과 Direct2D 그래프 구성을 줄인다. 실제 GPU pass 수를 하드웨어 timestamp로 검증한 결과는 아니므로 “GPU 3 pass→1 pass”로 주장하지 않는다.
- 단순 float 보간은 ACB 출력에서 최대 채널 차이 3을 만들었다. 기존 inside·outside의 UNORM8 중간 반올림을 셰이더 안에서 각각 재현한 뒤 더해, 이번 장치의 원래 출력과 맞췄다. 현재 target과 입력 비트맵은 8비트 premultiplied BGRA다. alpha mask의 RGB는 보간에 쓰지 않는다.
- 현재 target의 cropped origin·transform·coverage, 배경 CopyFromBitmap·Flush·최종 EndDraw와 원래 512px 타일 격자는 유지한다. 투명도·mask 생성/적용 순서와 PDF 저장 내용은 바꾸지 않는다.
- Windows SDK FXC로 HLSL을 빌드 시 컴파일해 bytecode를 DLL에 넣는다. 추가 런타임 컴파일러나 별도 shader 파일을 배포하지 않는다. factory 등록 또는 effect 생성이 실패하면 기존 세 Composite 노드를 사용하며 worker도 등록 상태를 이어받는다.
- 구현 근거: [Microsoft Composite 연산식](https://learn.microsoft.com/en-us/windows/win32/direct2d/composite), [Direct2D custom effect의 transform·shader 등록](https://learn.microsoft.com/en-us/windows/win32/direct2d/custom-effects).

## 비교 조건

- Windows / Intel Iris Xe hardware / PyMuPDF 1.28.2 / 숨김 HWND / 1200×900 물리px / 96 DPI. ACB 2019·2015의 첫 페이지를 화면 중앙에 두고 화면 맞춤·100%·200%를 비교한다. 이미지 준비 배율은 1로 고정한다.
- 조건당 준비 3회 + 측정 15회, 두 DLL을 번갈아 실행하며 순서를 교대한다. 두 번째 회차는 DLL 준비 순서도 뒤집는다. 측정 중 다른 GPU 테스트나 빌드를 함께 실행하지 않는다.
- 매 표본 새 장면 identity로 페이지·그룹·기존 정밀 타일 결과 재사용을 막는다. 준비된 immutable geometry·이미지 업로드는 공통으로 유지한다. 최초 PDF 열기·장면 추출·업로드·확대 이미지 재추출은 포함하지 않는다.
- 실제 리더의 30ms 완료 확인 간격을 사용한다. 정밀 작업 요청부터 전체 viewport atlas가 준비·가져오기 완료될 때까지이며, 90ms 입력 안정화와 화면 Present/vsync는 제외한다. 첫 타일 면적도 두 DLL에서 같다.
- 절대시간은 시스템/GPU 상태에 따라 변한다. 과거의 440.8ms나 아래의 초기 7회 결과와 직접 빼서 개선율을 계산하지 않고, 같은 회차의 기준·후보를 비교한다. P95는 15개 표본의 nearest-rank 값이다.

## 다른 후보와 초기 실험

다음 수치는 최종 채택 전의 별도 표본이다. 정식 비교 표와 섞어 해석하지 않는다.

| 후보 | 초기 조건 | ACB 2015 화면 맞춤 전체 완료 | 판단 |
|---|---|---|---|
| 배경을 직접 지운 뒤 masked 결과를 더함 | 준비 3 + 측정 7회, 기존 제출 유지 | 523.8→588.2ms | 100%는 526.1→433.4ms였지만 화면 맞춤이 느려 제외 |
| 256px 타일 | 준비 3 + 측정 5회 | 436.6→438.2ms | 확대는 더 느려 제외 |
| 768px 타일 | 준비 3 + 측정 5회 | 436.6→438.1ms | 확대는 더 느려 제외 |
| 반올림 보정 전 단일 셰이더 | 준비 3 + 측정 7회 | 434.9→345.5ms | 최대 채널 차이 3이 생겨 중간 UNORM8 반올림을 보강 |

- 배경 직접 합성에서 제출까지 제거한 후보는 중첩 마스크 검증에 실패했다. scratch를 즉시 재사용하지 않거나 제출까지 참조를 보유하는 변형도 일부 중첩 출력이 달라 유지하지 않았다. 최종 구현은 배경 복사와 제출을 그대로 유지한다.
- 최종 반올림 보정의 별도 2회 품질 점검에서도 두 문서 여섯 BGRA가 모두 일치했다. 해당 2회 표본은 최종 성능 판단에 사용하지 않는다.

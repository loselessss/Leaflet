# Rust 도형 좌표 변환 비교

2026-10-31 · 미배포 1.37.3 · Windows x64 · 기존 Direct2D ABI 24

## 변경

Python의 도형별 ctypes 구조체 목록 생성과 최종 배열 복사를 PyO3 Rust 확장으로
대체했다. 입력 tuple은 그대로 읽고, 28바이트 명령을 단일 bytearray에 직접 쓴다.
Python은 이 버퍼를 복사 없이 ctypes 배열로 참조해 기존 동기 Direct2D API에 넘긴다.
도형·좌표·그리기 순서·이미지·합성·GPU 셰이더는 바꾸지 않는다. 결과 캐시를 추가하지 않는다.

확장이 없는 개발 환경 및 기존 list/float 변환 입력은 Python 경로를 유지한다.
배포 빌드는 Rust 모듈을 필수로 생성하고 포함한다. Rust 1.99.1, PyO3 0.27.2,
Python 3.12.14를 사용했으며 crate 버전/체크섬은 Cargo.lock에 고정했다.
확장 바이너리는 188,416바이트다. 바이너리 크기는 실행 중 메모리 사용량이 아니다.

## 방법

`python -m tests.benchmark_path_packer <PDF...> --output <JSON>`

- 페이지 1, source scale 1, 1200×900 출력. 기존 단순화·알파 결합 설정 유지.
- 추출된 Python 장면은 두 방식의 동일 입력으로 사용한다. PDF 추출 시간은 제외한다.
- 각 표본은 새 도형·bitmap·retained scene을 만든 뒤 해제한다. 렌더 결과 재사용 없음.
- Python/Rust 순서를 번갈아 실행하고 워밍업 1회 뒤 각 7회 중앙값을 사용한다.
- 독립 실행 두 번째에서는 문서 순서도 반대로 했다.
- packing은 고유 경로의 배열 변환만, preparation은 실제 리더의
  `_native_vector_draws` 전체(도형 변환·자원 생성·이미지 업로드·scene 생성)다.
  두 시간을 더하지 않는다. PDF 추출·프로세스 시작·최종 그리기는 preparation에 없다.
- 픽셀 검증은 워밍업의 맞춤·100%·800% 중앙 화면에서 GPU 완료와 BGRA readback 후 비교했다.

## 결과 (ms)

| 실행 | 문서 | 좌표 변환 Python → Rust | 전체 장면 준비 Python → Rust | 준비 단축 |
|---|---|---:|---:|---:|
| 1 | ACB 2015 | 320.03 → 26.79 | 732.80 → 390.33 | 46.7% |
| 1 | ACB 2019 | 260.04 → 14.28 | 465.02 → 285.91 | 38.5% |
| 2 | ACB 2015 | 295.14 → 22.76 | 643.35 → 288.01 | 55.2% |
| 2 | ACB 2019 | 177.43 → 11.09 | 414.90 → 211.72 | 49.0% |

ACB 2015는 고유 경로 3,471개/명령 118,252개, 2019는 144개/84,658개다.
두 문서의 모든 고유 경로에서 기존과 Rust 배열 바이트가 일치했다.
두 실행 모두 6개 화면(문서 2개 × 배율 3개)의 픽셀 해시도 일치했다.

절대 시간 편차는 컸지만 두 독립 실행 모두 개선됐다. 이 수치는 첫 화면 전체나
반복 그리기의 개선율이 아니다. 현재 추출 비용과 Direct2D 자체 도형 생성 비용은 남는다.
800% 검증도 source scale 1을 사용했으므로 고해상도 이미지 재추출 시간을 측정한 것은 아니다.
추가 Python 객체와 배열 복사는 줄었지만 RSS/VRAM 감소량은 따로 측정하지 않았다.

원본 PDF, 픽셀과 세부 표본 JSON은 비공개 `tmp/rust-audit/`에 보관한다.
일반화한 비교 도구와 경계값·fallback 테스트만 저장소에 포함한다.

## 검증

- float32 반올림·음수 0·작은 값·overflow/무한대/NaN·정수 및 잘못된 입력.
- 버퍼 소유권과 Python fallback, 원래 list 및 float 변환 입력 호환성.
- 기존 Direct2D 장면·마스크·knockout·변환 회귀 검사.
- Rust 의존성 원본 고지·체크섬·소스 링크를 설치본과 릴리스 소스에 함께 포함.

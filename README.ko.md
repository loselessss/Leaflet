# sPDF

[English](README.md) | 한국어

sPDF는 **GPU 렌더 파이프라인을 도입해 확대·이동과 화면 갱신이 빠른**
Windows 데스크톱 PDF 뷰어·편집기입니다. 실용적인 페이지 편집, 주석,
오프라인 OCR, 여러 문서 관리 기능을 하나의 프로그램에 담았습니다.
외부 링크나 선택형 모델 다운로드를 직접
사용하지 않는 한 문서는 사용자 컴퓨터 안에서 처리됩니다.

**현재 버전: 1.31.1** · 한국어·영어 인터페이스 · Windows

편집기에서 사각형·이미지를 추가하고 드래그 또는 mm 속성 입력으로 이동·크기를
조절할 수 있습니다. 자체 생성 개체는 PDF 저장 후 다시 열어도 편집할 수 있으며,
기존 PDF의 그림을 자동으로 편집 개체로 바꾸지는 않습니다.

확대 후 품질 갱신에서는 지원되는 벡터 내용을 재사용하며 이미지를 백그라운드에서
준비합니다. 앱만 업데이트할 때는 GPU 디스크 캐시를 유지하며, 호환되지 않는
렌더러나 문서 변경이 있으면 다시 준비합니다.

## 이런 작업에 사용할 수 있습니다

### 편안하게 읽고 탐색하기

- 일반 PDF와 암호 PDF를 열고, 긴 문서도 현재 쪽 주변만 렌더링해 부담을 줄입니다.
- 읽기·편집 창에서 최대 800%까지 즉시 확대·축소한 뒤 보이는 부분을 선명하게 갱신합니다.
  지원되는 Windows 환경에서는 Direct2D가 보이는 타일을 캐시하고 합성합니다.
- 읽기 창의 도구 모음·보기 메뉴 또는 Ctrl+[ / Ctrl+]로 현재 쪽을 좌우로 돌려 봅니다.
  읽기 회전은 임시 화면 방향이며 PDF 파일은 바뀌지 않습니다. 방향을 저장하려면
  편집 창에서 회전합니다.
- 왼쪽 패널을 페이지 미리보기·PDF 책갈피·숨김 중에서 선택합니다.
- 확대 상태에서는 왼쪽 썸네일의 원하는 지점을 누르거나 파란 확대 영역 네모를
  드래그해 본문을 옮깁니다. 페이지 순서 변경은 전용 페이지 구성 화면에서만 합니다.
- 두 장 보기, 전체 화면, 프레젠테이션 모드를 사용하고 Alt+←/→로 이전 쪽·배율·
  스크롤 위치를 오갈 수 있습니다.
- 문서를 다시 열면 마지막으로 읽던 위치를 복원하고, Ctrl+클릭으로 문서 안이나
  웹 링크를 엽니다.

### 문서 편집하고 구성하기

- 독립 실행 시 읽기 전용 창으로 시작합니다. 리본 왼쪽의 **편집 모드**
  버튼이나 Ctrl+E로 **별도 OS 프로세스의 편집 창**을 열면 상세 편집 화면으로 시작합니다.
  편집기가 문서를 정상적으로 연 뒤에는 같은 파일의 리더 탭을 닫고, 마지막 탭이었다면
  리더 창과 프로세스도 종료합니다. 열기 실패·시간 초과 때는 리더를 그대로 유지합니다.
- **도움말 → 시작 모드**에서 리더 우선(기본값) / 편집 우선을 선택합니다. 다음 실행부터
  적용됩니다. 편집 창의 **파일 → 읽기 창 열기**는 미저장 확인 후 리더로 문서를 넘기고
  해당 편집 탭을 닫습니다.
- 모드 전환 중에는 대상 창의 열기 성공을 확인할 때까지만 두 프로세스가 잠시 겹칩니다.
  전환 뒤 편집기가 종료·충돌하면 파일을 리더로 다시 열 수 있으며 미저장 복구 사본은
  편집 프로세스와 독립적으로 유지됩니다.
- 각 작업 창은 독립된 임시 사본을 읽습니다. 저장 파일을 완성·검증한 뒤 백업하고
  교체하며, 저장 완료 알림을 받은 리더만 새 사본으로 갱신합니다. 갱신 실패·시간 초과나
  교체 직후 편집기 중단으로 알림이 없으면 마지막 정상 문서를 유지합니다.
- 다른 편집기가 원본을 먼저 저장했다면 덮어쓰지 않고 **다른 이름으로 저장**하도록
  안내합니다. 다른 프로그램이 원본을 잠그면 저장에 실패할 수 있지만 편집 내용과
  미저장 복구 사본은 유지됩니다.
- **페이지 구성** 버튼이나 Ctrl+Shift+P로 별도 바둑판 창을 열어 페이지를 드래그해
  순서를 바꿉니다. 페이지를 두 번 누르거나 선택 쪽 편집을 누르면 상세 편집으로 돌아오며,
  미저장 변경과 실행 취소·다시 실행 이력은 유지됩니다. 긴 문서도 보이는 쪽과
  그 주변의 미리보기만 렌더링합니다. 상세 편집 아래 상태표시줄에는 현재 쪽의 기본
  크기를 mm 단위로 표시합니다.
- 독립 실행 창은 제목표시줄에 탭을 배치하고 **[읽기/GPU]**, **[편집/CPU]**처럼 표시합니다.
  GPU 합성이 아닌 실제 페이지 래스터화를 기준으로 하며, 혼합 경로는 **CPU+GPU**로 표시합니다.
  프레젠테이션·전체화면
  기능은 읽기 창에서 사용하며, 독립 편집 창에서는 제공하지 않습니다.
- 편집 창에서 글자 내용·크기·색상을 바꾸고 페이지 구성·주석·수동 OCR을 사용할
  수 있습니다. 텍스트 편집은 도구 모음의 전용 아이콘으로도 켜고 끕니다.
- 편집 모드에서 현재 쪽의 캔버스 크기와 도련 박스를 조정하고, 우클릭 메뉴로
  편집 가능한 텍스트 요소 크기를 바꿀 수 있습니다.
- 텍스트 선택·검색·복사와 형광펜·메모 주석을 지원합니다.
- 일반 PDF와 OCR 처리된 PDF의 글자를 수정하고 실행 취소·다시 실행할 수 있습니다.
- 페이지 회전·삭제·순서 변경·삽입·병합·분리·추출을 지원합니다.
- PDF 책갈피를 추가하고 이름·순서·계층을 바꾸거나 삭제할 수 있습니다.
- 일반 TXT 파일에서 계층형 PDF 책갈피를 불러올 수 있습니다.
- 미리보기에서 남길 영역을 드래그해 현재 쪽·지정 범위·전체 쪽의 여백을 자릅니다.
- 선택한 쪽에 텍스트 워터마크를 넣고 이미지→PDF, PDF→PNG/JPEG 변환을 할 수 있습니다.
- 하나의 인쇄 창에서 미리보기·프린터·자동/세로/가로 방향·매수·전체/현재/지정 쪽·
  역순·단면/긴 쪽 양면/짧은 쪽 양면을 모두 선택할 수 있습니다.
- 무손실·균형·강한 압축 중에서 골라 PDF 용량을 줄입니다.

### 스캔 문서 다루기

- 기본 RapidOCR로 한국어·영어 OCR을 컴퓨터 안에서 실행하며 인터넷 연결이
  필요하지 않습니다.
- 스캔 PDF에 검색·선택 가능한 투명 텍스트 층을 추가하고, 인식된 위치를 기준으로
  글자를 수정할 수 있습니다.
- 더 어려운 페이지에는 별도로 설치하는 고용량 PaddleOCR-VL을 선택할 수 있습니다.

### 데스크톱 작업 흐름 이어가기

- 여러 문서를 탭으로 열고, 저장 여부와 관계없이 같은 모드의 sPDF 창 사이로
  탭을 드래그해 옮깁니다. 읽기 탭과 편집 탭은 서로 섞이지 않습니다.
- 즐겨찾기·최근 파일, 미리보기 현재 위치 표시, 폭 맞춤·쪽 맞춤, 손 도구·텍스트
  선택 도구를 제공합니다.
- 독립 실행본이 비정상 종료되면 원본과 분리된 사본에서 미저장 작업을 복구할 수
  있으며 원본을 자동으로 덮어쓰지 않습니다.
- PDF 호환 정보가 포함된 Adobe Illustrator(`.ai`) 파일을 열고, 편집 결과는 PDF로
  저장해 Illustrator 원본을 보존합니다.
- 인터페이스·도움말·설치 프로그램·업데이트 안내·릴리스 노트를 한국어 또는
  영어로 볼 수 있습니다.

## 설치

[GitHub 최신 릴리스](https://github.com/loselessss/sPDF/releases/latest)에서
Windows 설치 파일을 내려받을 수 있습니다. 설치 프로그램은 현재 사용자의
**연결 프로그램** 목록에 sPDF를 추가할 수 있지만 Windows 기본 PDF 앱을 몰래
강제 변경하지 않습니다.
시작 메뉴에는 **sPDF 리더**와 **sPDF 편집기**가 각각 등록됩니다. 설치할 때
리더·편집기 바탕 화면 바로가기를 따로 선택할 수 있으며, 두 바로가기는 같은
프로그램을 지정한 작업 모드로 실행합니다.

sPDF의 **도움말 → PDF 기본 프로그램 / 브라우저 설정**에서는 현재 Windows 연결
상태를 확인하고 Edge·Chrome·Firefox의 PDF 링크를 Windows 기본 PDF 앱으로 넘기는
사용자별 옵션을 설정할 수 있습니다.

자동 업데이트는 마지막 확인 후 24시간이 지났을 때만 확인합니다. **도움말 →
업데이트 확인**에서는 언제든 수동 확인할 수 있으며, 내려받은 설치 파일은 릴리스
버전과 SHA-256 값이 일치할 때만 실행합니다.

## 자주 쓰는 단축키

| 단축키 | 기능 |
| --- | --- |
| Ctrl+O / Ctrl+S / Ctrl+P | 열기, 저장, 인쇄 |
| Ctrl+F | 텍스트 찾기 |
| Ctrl+E | 읽기 창에서 편집 창 열기 / 편집 창에서 텍스트 편집 켜기·끄기 |
| Ctrl+Shift+P | 별도 페이지 구성 창 열기 |
| Ctrl+Z / Ctrl+Y | 실행 취소, 다시 실행 |
| Ctrl+B | 현재 쪽을 책갈피에 추가 |
| Alt+← / Alt+→ | 이전 보기, 다음 보기 |
| Ctrl+R / Ctrl+Shift+R | 현재 쪽 OCR, 전체 문서 OCR |
| F5 / F11 | 읽기 창에서 프레젠테이션, 전체 화면 |

프로그램에서 **F1**을 누르면 전체 한국어 사용법을 볼 수 있습니다.

## 알아둘 점

- 텍스트 편집은 원래 줄이나 상자 안의 내용을 교체하는 방식입니다. 문단 전체가
  자동으로 다시 배치되지는 않으며 대체 글꼴의 모양이 달라질 수 있습니다.
- 독립 실행 리더와 편집기는 지원되는 Windows 환경에서 화면 크기의 Direct2D 표면으로
  표시하며, 사용할 수 없으면 Qt/OpenGL 또는 CPU 표시로 전환합니다. 지원되는 페이지는
  벡터와 원래 glyph 윤곽을 Direct2D로 래스터화하고 디코딩한 이미지도 그곳에서 합성합니다.
  중첩된 벡터·텍스트 클리핑, 색이 입혀지는 단색 이미지 마스크와 일반 격리 투명도
  그룹도 지원합니다. 그라데이션은 페이지 범위 안에서 제한된 고품질 이미지로 만든 뒤
  Direct2D가 합성합니다. 소프트/이미지 클리핑 마스크, 복잡한 선 모양, 윤곽선 글자와
  선을 이용한 클리핑도 GPU 경로를 사용합니다. 격리 그룹의 Soft Light·Multiply·Screen·Overlay
  및 Hue·Saturation·Color·Luminosity를 포함해 Normal 외 표준 PDF 혼합 모드 15개를
  GPU 효과로 처리하며, 중첩된 도형·텍스트 클리핑 안의 혼합도 지원합니다.
  알파·밝기·이미지 마스크 안의 혼합과 도형 클리핑도 지원합니다. 밝기 마스크는
  MuPDF의 마스크 전용 색 변환에 맞춘 GPU 색상표를 재사용합니다.
  비격리·knockout 그룹과 마스크 보정 함수는 CPU 대체 경로를 유지합니다.
  비균일 변형 윤곽선 글자와 미지원 효과도 전체 CPU 경로를 사용하므로 아직 GPU 전용 엔진은 아닙니다.
  혼합 임시 버퍼는 화면 크기로 제한하며 표면별 예약 상한은 256 MiB입니다.
  내장 모드의 표시 방식은 그대로 유지합니다.
- 리더·편집기의 미리보기는 현재 한두 쪽만 유지하고, 선명한 부분 이미지 캐시는 탭당
  64 MiB로 제한합니다. 앱 전체 메모리 사용량을 64 MiB로 제한한다는 뜻은 아닙니다.
- 여백 자르기는 보이는 영역만 바꾸며 숨겨진 내용을 삭제하지 않습니다. 여백과
  책갈피 변경은 실행 취소·다시 실행할 수 있습니다.
- TXT 책갈피는 `1 | 소개`, `소개 | 1`, `1 소개` 형식을 지원합니다. 하위 항목은
  앞에 공백 두 칸 또는 탭 하나를 넣습니다.
- 양면 인쇄에는 양면 기능을 지원하는 프린터와 드라이버가 필요합니다.
- 작업 창마다 원본 크기 정도의 임시 디스크 공간을 사용합니다. 강제 종료 시 남은
  임시 사본은 운영체제의 임시 파일 정리 대상이며 복구 사본과는 별개입니다.
  저장 잠금용 `.spdf-save.lock` 파일은 남아 있어도 정상이며 잠금 자체는 프로세스 종료 때 해제됩니다.
- 자동 갱신은 연결된 작업 창 사이에 적용됩니다. 리더를 새로 실행하거나 연결이
  끊긴 뒤의 문서는 다시 열어서 디스크의 최신 저장본을 확인합니다.
- 미저장 복구 사본은 편집 중 30초 간격으로 갱신합니다. 보호된 PDF와 512 MB를
  넘는 사본은 제외하며, 복구한 문서는 먼저 **다른 이름으로 저장**합니다. 복구는
  평소 저장을 보조하는 기능이지 대신하는 기능은 아닙니다.
- PDF 호환 `.ai` 파일은 내부의 PDF 표현을 읽는 방식입니다. 저장할 때는 Illustrator
  원본을 덮어쓰지 않고 PDF를 만듭니다.

sPDF는 Python, PyQt5, PyMuPDF와 작은 Windows Direct2D 렌더러로 개발되었습니다.
RapidOCR은 별도 작업 프로세스에서 실행되어 OCR을 요청할 때만 관련 런타임을 불러옵니다.

그래픽 문제 확인이 필요하면 실행 전 `SPDF_DISABLE_GPU=1`을 설정해 CPU 표시 경로를
사용할 수 있습니다. 이때도 부분 렌더링과 즉시 확대·축소는 유지됩니다.
독립 실행 도움말 메뉴의 **화면 렌더러**에서 **자동**, **GPU(Direct2D)**,
**CPU(PyMuPDF)**를 선택할 수도 있으며 변경 후 sPDF를 다시 실행합니다. 문서
창 제목의 `[GPU]` / `[CPU]` 표시로 현재 실제 동작 경로를 확인할 수 있습니다.
Direct2D 하드웨어를 사용할 수 없는 PC에서는 GPU 선택이 비활성화됩니다.
같은 메뉴의 **렌더링 진단 표시**를 켜면 현재 페이지를 CPU 렌더링, GPU 렌더링,
CPU+GPU 렌더링 또는 현재 CPU·GPU 준비 중으로 명확히 구분합니다. 도움말 풍선에서는
현재 상태와 GPU 장면 구성을 확인할 수 있습니다.

```bash
pip install PyQt5 PyMuPDF rapidocr onnxruntime
python run.py
python run.py 문서.pdf
python run.py --workspace editor 문서.pdf
```

콘솔 없이 실행하려면 `run.pyw`를 사용합니다. Windows 설치본은 `build_exe.bat`을
먼저 실행한 다음 `build_installer.bat`으로 만듭니다.

### 외부 모듈에서 읽기 전용으로 사용

호스트의 `QApplication`이 실행 중인 상태에서 창을 열 때 모드를 선택합니다.

```python
from pdfeditor.app import new_window

viewer = new_window("document.pdf", read_only=True)   # 읽기 전용
annotator = new_window("document.pdf", read_only=True,
                       annotations_enabled=True, autosave_annotations=True)
```

`AppWindow`도 같은 옵션을 받습니다. 읽기 전용에서는 확대·이동·검색·텍스트 선택/복사·
기존 메모 보기·인쇄를 유지하고 본문 편집·OCR·페이지/책갈피 변경을 막습니다.
`annotations_enabled=True`를 함께 지정하면 메모·형광펜과 실행 취소/다시 실행을 허용합니다.
이 모드에서는 원본 대신 PDF 옆의 `document.pdf.spdf-annotations.json`에 주석을 저장합니다.
`autosave_annotations=False`이면 Ctrl+S로 직접 저장합니다. Ctrl+Shift+S는 별도의
주석 포함 PDF를 만듭니다. 원본 PDF를 옮길 때는 주석 파일도 함께 옮겨야 합니다.

새 창에도 모든 옵션이 이어지며, 설정이 다른 창은 재사용하거나 서로 탭을 옮기지 않습니다.
설정은 창마다 고정되며 외부 모듈에서는 sPDF 자체 업데이터가 켜지지 않습니다.
리더 옵션, 저장·충돌 처리, 보호된 PDF의 제한은
[리더 API 연동 문서](docs/READER_INTEGRATION.md)에 정리했습니다.

Qt와 독립적인 `Document(path, read_only=True)`도 본문 변경 메서드를 호출하면
`PermissionError`를 발생시킵니다. 이는 기능 선택 옵션이며 DRM이나 파일 접근 권한
제한은 아닙니다. 복사와 인쇄는 계속 사용할 수 있습니다.

버전별 변경 내용은 [CHANGELOG.ko.md](CHANGELOG.ko.md), 설계 이력과 유지할 제약은
[PLAN.md](PLAN.md), 오픈소스 고지는 [LICENSES.md](LICENSES.md)에서 확인할 수 있습니다.
